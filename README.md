# CTF Writeups & Security Notes 🎯

Welcome to my central repository for Capture The Flag (CTF) challenges, security walk-throughs, and technical research notes. This repository serves as a documented proof of my practical engineering skills in identifying, analyzing, and exploiting software vulnerabilities.

## 📂 Repository Structure

*   **`OverTheWire-Bandit/`** - Deep-dive write-ups for Linux fundamentals and core terminal security.
*   **`TryHackMe-CTF/`** - Detailed walk-throughs for practical web exploitation rooms (RootMe, Simple CTF, etc.).
*   **`General-CTF-Challenges/`** - Solutions and analysis for various standard web and network security challenges.

## 📈 Methodology & Purpose

Every write-up here focuses on:
1.  **Vulnerability Identification:** How the flaw was discovered using manual and analytical techniques.
2.  **Exploitation (PoC):** Step-by-step reproduction of the security loophole with proper HTTP/Terminal logs.
3.  **Remediation:** Code-level fix recommendations to secure the infrastructure against the analyzed threat.
